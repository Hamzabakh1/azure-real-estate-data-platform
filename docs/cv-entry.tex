\textbf{Azure Real Estate Data Platform --- Cloud Data Engineering}
\hfill\textcolor{steel}{\bfseries Projet personnel}\par

\begin{cvitems}

\item \textbf{Conçu une plateforme data Azure de bout en bout} pour consolider des flux immobiliers hétérogènes, avec Azure Data Factory pour l'orchestration, Azure Storage pour le data lake et Azure SQL Database pour les marts analytiques.

\item \textbf{Mis en œuvre une architecture Bronze / Silver / Gold} : snapshots bruts immuables et partitionnés, normalisation et déduplication, contrôles de schéma et règles métier, puis exposition de dimensions, faits et vues prêtes pour Power BI.

\item \textbf{Industrialiser la fiabilité opérationnelle} grâce aux identifiants de run, réconciliation, zone de quarantaine, reprises sur erreur, journalisation, RBAC via managed identity et supervision Azure Monitor / Log Analytics.

\end{cvitems}}
